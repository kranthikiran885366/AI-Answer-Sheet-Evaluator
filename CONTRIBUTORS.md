## Recognition Levels

### 🥇 Major Contributors
Individuals or organizations with significant contributions:
- 50+ commits
- Multiple feature implementations
- Documentation or infrastructure improvements

### 🥈 Active Contributors
Regular contributors to the project:
- 10+ commits
- Consistent participation in PRs and issues

### 🥉 Contributors
Those who have contributed code, documentation, or translations:
- 1+ commits
- Issue reports and feedback

## How We Recognize Contributions

Contributors are recognized in multiple ways:

1. **README Badge**: Added to the main README.md
2. **CONTRIBUTORS.md**: Listed on this page
3. **Release Notes**: Mentioned in release announcements
4. **GitHub**: Your contribution history is visible in the repository

## Adding Yourself

If you've contributed and would like to be added to this list, please:

1. Open a PR updating this file with your information
2. Include your GitHub username and a brief description of your contributions
3. Reference your merged PR(s) or issue contributions
